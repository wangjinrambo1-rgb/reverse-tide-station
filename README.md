## 三幕章节一览

1. **第一幕 · 验潮庭（三池潮汐）**：豆青瓷庭院与黄铜锅炉联动。需放空下池拾回遗失阀轮、涨潮升起荷台、依「短·短·长」叩响顶层验潮铜铃扣稳大浮球，并在 `135°` 视差对齐截水入盘，推开玉釉水亭双门。
2. **第二幕 · 回声双塔（双塔回声）**：在黄昏粉暮与镜面玻璃砖之间，操作蒸汽汇流拉闸、嵌入黄铜曲柄摇动转桥绞盘、联动加压双泵并聆听复现四拍双号角共鸣旋律，接通东门云道。
3. **第三幕 · 钟埠船闸（夜港船闸）**：夜幕星海下旋开海水蒸汽总阀与大钟咬合螺栓，以钟声反哺控制箱电力、配平五灯开关解缆，最终放闸送明轮船驶向月光海路终章。
4. **过场 · 踏云登阶**：每幕通关后触发 3/4 长焦天梯过场，16 级薄玉云阶随步履逐级破雾升起，唤醒十尊持盘古像步入云海圣门。

## 操作方式

### 手机 / 竖屏触控体验
- **点击地面 / 机关**：点击路点移动主角，点击交互机关或 NPC「瑟岚」触发对话。
- **单指滑动**：左右滑动平滑旋转 45° / 135° / 225° / 315° 四向正交磁吸视角。
- **双指捏合**：自由放大 / 缩小审视建筑与机械细节（底栏将自动显示 `1:1` 复位按钮）。
- **顶部任务条**：支持点击右上角 `▴ / ▾` 一键折叠或展开，腾出最大 3D 观赏视野。

### 桌面端体验
- **鼠标左键点击 / 拖拽**：点击路点寻路与交互；在场景空白处左右拖拽旋转视角（松手自动磁吸），按 `Q` / `E` 快捷左转 / 右转，`Esc` 关闭对话框。

## 工程精简与压缩优化说明

- 剔除 41 个开发过程冗余旧模型，仅保留实际运行的 **71 个 `.glb`** 模型、`5` 张九宫格/罗盘 UI 贴图与单页应用 `index.html`。
- 嵌入式 2048px 大贴图均收敛至 `1024px` WebP（漫反射 Q84 / 法线 Q90），69 个静态网格模型施加零抽面 `KHR_draco_mesh_compression` 纯几何压缩（完整保留原始节点名、层级结构及主角/瑟岚 52 骨动画）。
- 总发行包体从开发目录 **595.46 MB** 高保真瘦身至 **52.19 MB**（`-91.2%`，最大单文件仅 `3.02 MB`）。

```bash
python -m http.server 8765 --bind 127.0.0.1
```
